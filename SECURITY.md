# Security policy

This policy covers every public repository in the [OrnisLab](https://github.com/OrnisLab) organization, unless a repository has its own `SECURITY.md`.

## Reporting a vulnerability

Please **do not** open a public issue, pull request or discussion for a security problem.

1. Go to the affected repository and open the **Security** tab.
2. Choose **Report a vulnerability**.
3. Fill in the advisory form. Only the repository’s maintainers can see it.

## What to include

- The affected repository, version or commit
- A description of the issue and its impact
- Steps to reproduce, a proof of concept, or both
- Any logs, configuration or environment details that help us reproduce it

## What happens next

- We aim to acknowledge your report within **3 business days**.
- We confirm the issue, assess its severity and keep you updated while we work on a fix.
- When a fix is released, we publish a GitHub security advisory and credit you, unless you prefer to stay anonymous.

Please give us reasonable time to fix the issue before disclosing it publicly.

## Supported versions

Unless a repository states otherwise, security fixes go into the latest release only.

## Out of scope

This policy is for OrnisLab’s open-source projects. Ornis commercial products and İşNet services are handled separately; please contact İşNet through [isnet.net.tr](https://www.isnet.net.tr).
