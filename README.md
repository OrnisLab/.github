# OrnisLab `.github`

Organization-wide files for [OrnisLab](https://github.com/OrnisLab).

| Path | Purpose |
| :-- | :-- |
| `profile/README.md` | The overview shown on the organization page |
| `profile/assets/` | Cover banner, domain cards and avatar in light (used on the page) and dark versions, plus the white Ornis Recon logo |
| `SECURITY.md` | Default security policy for every repository without its own |
| `CONTRIBUTING.md` | Default contributing guide for every repository without its own |
| `tools/build_assets.py` | Regenerates the images in `profile/assets/` after a wording change |
| `tools/brand/` | Source logos the images are built from |

Repositories show up under a domain card when they carry its topic: `ornis-guard`, `ornis-vista`, `ornis-recon` or `ornis-secops`.
